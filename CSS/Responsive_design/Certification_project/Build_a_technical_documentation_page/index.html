Introduction

Bash (Bourne Again SHell) is a command language interpreter for the GNU operating system. It is widely available on various versions of Unix and is the default shell on most Linux distributions and macOS. Bash can be used both as an interactive login shell and as a scripting language to automate tasks.

Bash provides a rich set of built-in commands, control structures, and features such as command history, job control, aliases, and shell functions. It can be extended for a variety of purposes; for example:

  • Interactive use: Bash serves as the user's command interface to the operating system, allowing you to run programs, manage files, and control processes directly from the terminal.
  • Shell scripting: Bash scripts automate repetitive tasks, system administration, file processing, and complex workflows by combining commands into reusable programs.
What you should already know

This guide assumes you have the following basic background:

  • A general understanding of operating systems and the concept of a 111 file system with directories and files.
  • Basic familiarity with using a terminal or command prompt.
  • Some experience with any programming language is helpful but not required. If you are new to programming, Bash is a great place to start for system automation tasks.

Bash is one of many available Unix shells. While the original Bourne Shell (sh) established the foundation, Bash extends it with features like command-line editing, command history, and improved scripting constructs. Other popular shells include Zsh, Fish, and Ksh, each with their own syntax and features.
